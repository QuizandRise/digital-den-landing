# 4. WorkforceDen Fairness Principles

| **Principle**                     | **Mandatory interpretation**                                                                                                     |
|-----------------------------------|----------------------------------------------------------------------------------------------------------------------------------|
| P1. Explainability                | Material decisions must include a reason category, policy basis, impact, available remedy and appeal route.                      |
| P2. Proportionality               | The system must use the least restrictive intervention that adequately controls the risk.                                        |
| P3. Separation of concerns        | Account restrictions, project access, file access, payment holds and dispute actions must be separately controlled.              |
| P4. Human review                  | High-impact decisions involving identity, livelihood, money or permanent access must be reviewable by an authorised person.      |
| P5. Evidence before enforcement   | A report or automated flag is a trigger for assessment, not proof of wrongdoing.                                                 |
| P6. Role-appropriate transparency | Each user sees all information needed to understand their own position, but not internal margins or another user’s private data. |
| P7. Accessibility by default      | Accessible interaction is a product requirement, not a later accommodation.                                                      |
| P8. Data portability              | Users retain appropriate access to contracts, invoices, purchased deliverables and lawful account records after closure.         |
| P9. Predictable fees              | Fees must be shown before acceptance and locked for the agreed contract version unless both parties accept a change.             |
| P10. Auditable operations         | Sensitive decisions and state changes must produce an immutable audit trail.                                                     |

# 5. Verified Marketplace Model

## 5.1 Professional entry

1. Create permanent account and verify email.
2. Complete private identity and eligibility profile.
3. Provide skills, services, languages, work history and portfolio.
4. Complete identity, right-to-work and payout onboarding checks appropriate to jurisdiction.
5. Undergo manager review before public visibility.
6. Choose availability and service capacity.
7. Publish only approved public-profile information.

## 5.2 Client entry

1. Create permanent personal or business account.
2. Verify email and complete risk-appropriate contact/payment checks.
3. Search professionals and teams or submit a matching request.
4. Negotiate through the platform and formalise the agreement as an Offer.
5. Accept the Offer and fund the project before delivery begins where required.

## 5.3 Capacity-led service visibility

A service category should become searchable only when at least one
approved professional or team has verified capability and active
capacity. Categories with no current capacity should be hidden, marked
unavailable, or offered through a managed matching request. WorkforceDen
must not advertise supply it cannot reliably fulfil.

# 6. Search, Ranking and Discovery

## 6.1 Search result composition

- Individual professionals.
- Verified teams, including the Digital Den network.
- Relevant service categories generated from approved profiles.
- Availability, response expectations and service location/language filters.

## 6.2 Explainable ranking

Ranking must not be a black box. Professionals should see which
controllable factors affect visibility. No single private signal should
silently destroy visibility.

| **Permitted ranking factor** | **User-facing explanation**                                    |
|------------------------------|----------------------------------------------------------------|
| Verified skill match         | Your verified services match the client’s query.               |
| Profile completeness         | Complete profiles provide clearer information to clients.      |
| Availability and capacity    | Profiles marked available may rank above unavailable profiles. |
| Response reliability         | Consistent, timely responses improve service reliability.      |
| Delivery reliability         | On-time, accepted work supports trust.                         |
| Quality and satisfaction     | Multi-dimensional feedback contributes proportionately.        |
| Relevant experience          | Comparable completed projects may improve relevance.           |

## 6.3 Prohibited ranking practices

- Permanent or severe visibility reduction without an identifiable reason category.
- Pay-to-rank mechanisms that overpower relevance and verification.
- Using disputed or overturned moderation events as permanent negative signals.
- Using protected characteristics or close proxies as ranking factors.
- Allowing one anomalous review to dominate the score.
